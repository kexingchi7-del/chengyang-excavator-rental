## 本机使用

直接双击 index.html，或在本目录运行 `python3 -m http.server 8080` 后访问 http://localhost:8080。

## 询价功能

表单整理客户资料并估算机械费，通过 FormSubmit 发送表格邮件。启用需要邮箱验证后取得匿名表单编号，填入 form.js 的 FORM_ID。编号未配置时不会发送资料，也不会显示提交成功。公开源码不保存收件邮箱。尚未接入在线付款或电子签约。
